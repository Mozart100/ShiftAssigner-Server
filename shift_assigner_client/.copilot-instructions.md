# Copilot Instructions for ShiftAssigner Client

## Development Environment Setup

### Android Emulator Configuration
- **Default Emulator**: Pixel_4
- **Command to start**: `emulator -avd Pixel_4`
- **Expo Connection**: Automatically connects to Pixel_4 when running `npx expo start`

### Development Workflow
1. Start Expo development server: `npx expo start`
2. Launch Pixel_4 emulator (if not already running)
3. Press `a` in Expo terminal to connect to Android emulator
4. App will automatically load on Pixel_4 device

### Notes
- Pixel_4 emulator has been tested and confirmed working
- Other emulators (Medium_Phone_API_36.0, Pixel_8a, Pixel_9) may have compatibility issues
- Always use Pixel_4 for consistent development experience
